Get Fluent ready

Fluent is an input method: it improves the English you type and types Chinese, right in the app you're using.

  • Input method installedRun make install in the source folder.
  • Added in Input SourcesSystem Settings ▸ Keyboard ▸ Input Sources ▸ + ▸ English ▸ Fluent. macOS doesn't let apps add it for you.
  • SelectedPick Fluent from the input menu in the menu bar, or press Ctrl+Space.
  • API key setNeeded to improve English. Chinese works without it.
  • Dictionaries presentmake install downloads them from rime-ice.

Double-tap Shift turns Fluent on and off, for terminal commands or passwords.

Enter inserts the improved text; Shift+Enter inserts it as typed.

Rewrite

Fluent sends what you type to an OpenAI Responses-compatible API and shows the improved text in the bar.

Chinese

English always comes first: Chinese converts only when the letters you type can't be English.
